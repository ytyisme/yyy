# EiliEili

独立的视频发布和观看网站。运行 `python3 server.py`，访问 `http://127.0.0.1:8082/`；同一服务器的访问者可发布和播放视频。视频保存在 `.data/videos/`，资料保存在 `.data/videos.sqlite3`；备份整个 `.data` 目录即可保留数据。可通过环境变量 `EILIEILI_DATA` 和 `EILIEILI_PORT` 指定数据目录和端口。支持 MP4 / WebM，单个视频不超过 100 MB。昵称由发布者填写，不包含账号、审核或删除功能。视频保存在运行此服务的机器上，服务停止后无法访问；需配置外部服务器才能供互联网用户使用。
