# 第16关 · 笑脸追逐

场景参考：https://www.bilibili.com/video/BV1BTwgzLEK2/ （Level ! 红色长廊）。场景使用本项目的 Three.js 几何构建，可实际移动、换道和跳跃。

背景音乐：https://www.bilibili.com/video/BV1we4y1d7Pj/ 。`level-run-theme.m4a` 是指定视频的公开 AAC 音轨，原视频时长201秒；游戏内循环播放，可暂停和静音。

`smiler.png` 是用户在 2026-10-11 提供的怪物图片，原样保存并用作身后怪物的纹理。

玩家参考：用户上传的《截屏2026-10-11 17.39.04.png》，保留原图作为关卡参考预览；游戏角色由Three.js几何体制作。
联机线路说明：[EMQX](https://www.emqx.com/en/mqtt/public-mqtt5-broker)、[HiveMQ](https://www.hivemq.com/mqtt/public-mqtt-broker/)。
