# Cinema ending

`forest-outro.mp4` is the user-selected ending clip, “早安大森林”.

Source: https://www.bilibili.com/video/BV1syZWBXEKr/

Included for the requested local cinema game. The clip is played as an unnumbered ending with the browser's native video element, which provides a real `ended` event for relighting the hall. It is not a fourth entry in the movie selector.

`film-three.mp4` is the user-selected third film, “从前有座饽饽山😍”.

Source: https://www.bilibili.com/video/BV1Z8gP6eEFL/

It uses the native video element so its real `ended` event can automatically start the ending clip. No timer estimates the end of either clip.
