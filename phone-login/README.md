# 游戏的手机号演示登录

默认使用演示验证码：填写格式正确的手机号，点击“获取演示码”，页面直接显示 6 位数字。输入同一个号码对应的演示码即可进入游戏，不发送短信，也不需要短信账号。本地文件和静态网页使用浏览器演示流程；专用服务器使用演示会话。演示码不能证明手机号的归属，线上游戏仍由 Sites 的所有者私有访问权限保护。

## 当前状态

登录页面、演示码生成、验证、游戏跳转与退出已完成。演示码 5 分钟有效；每次生成后等待 60 秒可重新获取，必须使用本次号码对应的码。浏览器只保存带有效期的昵称和号码掩码，不保存完整手机号。

如以后需要真实短信，可用 `--sms` 明确启用原短信服务。该模式仍需要服务商账号、已审核签名和模板、API 密钥以及独立 HTTPS 服务器；未配置时不会自动降级为演示登录。

## 预览页面

在项目目录执行：

```sh
rtk proxy python3 -u scripts/serve-phone-app.py
```

打开 `http://127.0.0.1:8081/phone-login/`，直接获取演示码并登录。该服务器默认仅监听本机，演示数据和真实短信数据分开保存。如设置了 `GAME_OWNER_PHONE`，服务器演示模式也只接受该号码；未设置时接受任意格式正确的号码。

也可直接打开本目录的 `index.html`，或使用现有静态游戏服务器打开 `/phone-login/index.html`。真实短信模式的启动命令是 `rtk proxy python3 -u scripts/serve-phone-app.py --sms`。

## 接通腾讯云短信

按 [腾讯云短信快速入门](https://cloud.tencent.com/document/product/382/3778) 开通服务、创建应用、申请签名和验证码模板。国内短信需要可用的短信套餐，签名和模板通过审核后才可发送；参考 [腾讯云接口前提条件](https://cloud.tencent.com/document/product/382/43197)。

此接口使用两个模板参数，按顺序为“6 位验证码”和“有效分钟数”。示例正文可写成“您的登录验证码为{1}，{2}分钟内有效。请勿将验证码告知他人。”，实际内容以审核通过的模板为准。接口规范见 [发送短信 API](https://cloud.tencent.com/document/api/382/55981)。

将 `.env.example` 复制为同目录的 `.env`，在本机或服务器私下填写以下配置，不要把密钥粘贴到聊天、浏览器代码或 Git：

| 配置 | 含义 |
| --- | --- |
| `GAME_OWNER_PHONE` | 唯一允许登录的手机号，可用 11 位号码或 +86 格式 |
| `TENCENTCLOUD_SECRET_ID` / `TENCENTCLOUD_SECRET_KEY` | 具有发送短信权限的服务端密钥 |
| `GAME_SMS_APP_ID` | 短信应用的 SdkAppId |
| `GAME_SMS_SIGN_NAME` | 已审核签名的名称 |
| `GAME_SMS_TEMPLATE_ID` | 已审核的验证码模板 ID |
| `GAME_SMS_REGION` | 默认 ap-guangzhou |
| `GAME_PHONE_ORIGIN` | 实际访问的完整源地址；线上必须为 HTTPS |

环境变量优先于 `.env`。`.env` 与 `.phone-login-data/` 已加入忽略列表。登录数据存储在该私有目录的 SQLite 中；验证码是服务器密钥计算的摘要，会话是随机令牌的摘要。不要在普通静态服务器中发布整个源码目录。

## 线上部署

真实短信模式使用能持久保存 `.phone-login-data/` 且支持 Python 3 的 HTTPS 服务。反向代理只转发到本机 127.0.0.1:8081，并保留实际 HTTPS 域名的 Host。将 `GAME_PHONE_ORIGIN` 设置为该域名，不包含路径或末尾斜杠，再启动 `scripts/serve-phone-app.py --sms`。该服务器忽略转发的客户端 IP，短信限流还有全局手机号额度，不能通过伪造 X-Forwarded-For 绕过。

所有游戏请求必须经过这个服务器。不要另外通过静态托管、CDN 或反向代理暴露未受保护的游戏文件。手机登录站点不要复用原 Sites 域名：该域名的私有访问边界由 Sites 管理。

验证码 5 分钟有效、只能使用一次；错误验证最多 5 次。每 60 秒最多发送一次，每小时最多 5 次、每天最多 10 次。服务商拒收或网络失败不会被显示成发送成功。登录会话保留 7 天，退出时立即作废。配置为 HTTPS 时 Cookie 使用 Secure、HttpOnly、SameSite=Lax。

此模式只缓存安装图标，不缓存可玩的游戏页面；离线时需要重新连接网络才能验证登录状态。游戏进度依然保存在当前设备，手机号登录不提供跨设备进度同步。
