# 第 19 关 · 真实音乐音源

这些歌都是网上的正版曲目，游戏里不能直接盗链打包。

## 用法（二选一）

### 1）本地文件（推荐）
把你自己下载/购买的 mp3 放到本目录，文件名例如：

- x-cool.mp3
- 天真的橡皮.mp3
- 中国人能飞.mp3
- NO-BATIDAO.mp3
- 哎刀马刀马.mp3
- 辛巴巴.mp3

### 2）网上直链
编辑 `playlist.json`，给对应歌曲填可直接播放的 `url`（须是 .mp3/.ogg 等音频直链，且允许跨域）。

```json
{
  "id": "naive-eraser",
  "title": "天真的橡皮",
  "url": "https://example.com/your-file.mp3"
}
```

播完六首即通关；小球碰壁会叠一层敲击音。
